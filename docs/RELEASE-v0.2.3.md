# Vegas Co-op v0.2.3

Fixed the $1,000 reward in Vegas stage 3-5 for the WASD player in Campaign and Campaign Endless. The shared balance stays numeric, and the next stage calculates its target from the correct balance and previous target.

修复剧情战役和战役无尽中，WASD 玩家抓取维加斯 3-5 关的女性角色后显示 `$jewl2`、共享金额变成 `NaN` 的问题。现在奖励正常计入 $1,000，下一关会用正确的余额和上一关目标计算新目标。

To upgrade, close the game, run the previous version’s `Uninstall.cmd`, then install this version. The installer leaves existing saves as they are.

升级时先关闭游戏，用旧版的 `Uninstall.cmd` 卸载，再安装新版。安装器保留现有存档。
