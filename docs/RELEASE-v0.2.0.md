# Vegas Co-op v0.2.0

Local two-player support for **Arcade → Campaign** and **Campaign Endless** in Gold Miner: Party Rush.

- WASD / arrow-key players, independent left/right mouse aiming.
- Per-player early recall and dynamite; shared money, goals, timer, shop and inventory.
- Collapsible modifier panel with fast launch and fast return.
- Swimming-ring movement and co-op across all campaign mining scene entries.
- Portable install/uninstall using Windows PowerShell; original-pack backup and strict SHA-256 validation.

**Requires Steam app 4815320, build 26941259, game version 0.6.5 and an exact matching original Vegas pack.** Uninstall older/different mods first. Close the game, extract the full ZIP and run `Install.cmd`. Launch from Steam as usual. Run `Uninstall.cmd` to restore the original.

No Python, Java, Node.js or decompiler is needed for installation. Only the Vegas pack is modified; saves, app.asar, signed integrity metadata, Steam DLLs and anti-cheat binaries are unchanged.

Validation: original Vegas page and bundled Ruffle; both native modes, 55 mining scene entries each, input separation, shared rewards, recall, bombs, speed switches and settlement. The portable installer passed 9 isolated-copy checks. This does not claim a full playthrough or testing on another physical PC.
