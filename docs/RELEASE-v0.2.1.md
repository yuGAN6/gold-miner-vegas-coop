# Vegas Co-op v0.2.1

The modifier panel now follows the selected game language:

- Chinese game language: Chinese panel text.
- English and all other game languages: English panel text.
- Button, options, help text, accessibility label and connection status are translated together.
- In-page language changes preserve modifier switches and the expanded/collapsed state. Saved switches also survive a language reload.

Campaign and Campaign Endless co-op, independent early recall, dynamite, mouse aiming and speed modifiers remain available.

**Requires Steam app 4815320, build 26941259, game version 0.6.5 and an exact matching original Vegas pack.** Close the game. If an older release is installed, uninstall it first, then extract the complete new ZIP and run `Install.cmd`. No Python, Java, Node.js or decompiler is required. Saves are not modified.

The original Vegas page and bundled Ruffle were used for language/fallback tests and both modes' behavior and scene-entry regression checks. The portable installer was tested on isolated copies. A full playthrough and another physical PC remain unverified.
