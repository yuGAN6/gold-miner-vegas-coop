Gold Miner: Party Rush - Vegas Co-op v0.2.0

1. Close the game and extract the complete ZIP.
2. Run Install.cmd. If necessary, select the game folder containing
   Gold Miner Party Rush.exe. You can also drag that folder onto Install.cmd.
3. Launch from Steam: Arcade > Campaign or Campaign Endless.

Left player: A/D move or recall their own outgoing claw, S launch, W dynamite,
left mouse to aim. Right player: arrows, right mouse to aim.
Use the top-right Mod Tools panel for mouse aiming, fast launch and fast return.
Money, targets, timer, shop and dynamite inventory are shared.

Run Uninstall.cmd with the game closed to restore the verified original pack.
No Python, Java, Node.js or Flash decompiler is needed to install.

Supported: Steam app 4815320, build 26941259, game 0.6.5, exact matching
original resources/vegas/vegas.pack. Other versions/mods are refused.
Only the Vegas resource pack is changed. Game saves, app.asar, signed integrity
metadata, Steam DLLs and anti-cheat binaries are not modified.

Game updates or Steam file verification may remove the patch. Do not apply
this release to a different build. Uninstall an older/different mod first.

Source and updates: https://github.com/yuGAN6/gold-miner-vegas-coop
